## Описание проекта

Этот проект предназначен для сборки прошивки для устройства на базе микроконтроллера STM32F446. В репозитории содержатся исходные файлы, скрипты для компиляции, а также необходимые зависимости.

---

## Файлы для компиляции (сборки) прошивки

Для сборки проекта требуетcя установленный [Docker](https://www.docker.com/).

- **`compile.ps1`** — запуск компиляции в PowerShell (Windows).
- **`compile.bat`** — запуск компиляции в Command Prompt (Windows).
- **`compile.sh`** — запуск компиляции в shell (Linux).

---

## Скрипты

- **`dfu-convert`** — скрипт для создания DFU-файла, используется при сборке.

---

## Настройки IDE

- **`.vscode/`** — папка с настройками Visual Studio Code.
- **`REFLEX_v1.9.1.code-workspace`** — конфигурационный файл рабочей области для Visual Studio Code.

---

## Драйверы и библиотеки

- **`STM32_USB_Device_Library/`** — исходные коды драйвера USB от STMicroelectronics.

---

## Описание аппаратной части

- **`контакты.md`** — документ с описанием соответствия контактов на плате.

---

## Конфигурация сборки

- **`Makefile`** — файл описания правил сборки проекта.
- **`stm32f446.ld`** — файл линковки для линковщика.

---

## Исходные коды проекта

- **`Audio/`** — исходные коды модулей, связанных с обработкой аудио.
- **`User/`** — пользовательские исходные коды проекта.

---

## Внешние зависимости (загружаются автоматически при сборке)

Следующие библиотеки подтягиваются автоматически при выполнении сборки:

- **CMSIS Core** — `core/`
- **CMSIS Device F4** — `cmsis-device-f4/`
- **STM32F4xx HAL Driver** — `stm32f4xx-hal-driver/`

---

## Инструкция по сборке

### Windows:
- Запустите `compile.bat` в командной строке.
- Либо запустите `compile.ps1` в PowerShell (может потребоваться разрешение на исполнение скриптов).

### Linux:
- Запустите `compile.sh` в терминале.

После выполнения скрипта будет создан загрузочный DFU-файл с использованием утилиты `dfu-convert`.

---

## Поддержка IDE

Для разработки рекомендуется использовать **Visual Studio Code** с конфигурацией из файла `REFLEX_v1.9.1.code-workspace`.
